# LOOPA 0.5.0 — the 10 games

İsim Şehir runs on its original engine (unchanged). The other 9 games run on a common, server-
authoritative mode engine (`supabase/migrations/20261115000001_mode_engine.sql`, content in
`20261115000002_mode_content.sql`, generated by `tools/modes/build_content.py`).

**Status: migrations prepared and tested locally (plain PostgreSQL and a local Supabase stack). They
are NOT applied to the hosted project.** Until they are, the hosted backend has no mode engine: the
0.5.0 app then shows the new games without access information and cannot start them (İsim Şehir works
as before).

## Common engine
| Piece | Role |
|---|---|
| `mode_match_state` | per match: server-only state (turn order, used content, telephone start phrases…) and a public part (teams, team scores, chain, lives, totals) |
| `mode_rounds` | one row per round / turn / step: phase, actor, public data, results, deadline |
| `mode_secrets` | hidden words, cards and answers — no client access at all |
| `mode_submissions` | guesses, answers, votes, statements, chain words, telephone steps; points |
| `mode_strokes` | live strokes of Çiz ve Tahmin Et |
| `player_mode_stats` | per-game profile statistics, written once by a trigger when a match's rewards are processed |

- Client RPCs: `get_mode_state(room)` (per-player snapshot), `mode_act(round, kind, payload)`,
  `mode_draw(round, strokes)`, `get_strokes(round, after)`, `mode_skip(room)` (host), `get_my_mode_stats()`.
- `_advance` / `game_tick` dispatch non-İsim-Şehir matches to `_mode_advance`; `start_match` starts them
  (plan / rotation check unchanged, player minimum per game); `skip_reveal` also skips mode reveals;
  `get_match_results` returns `game_mode`, `mode_public` and `correct_actions`.
- Every action locks the room row (same lock as `game_tick`), checks that the caller is an active player
  of this match, that the round is the latest one, the phase and the deadline. Scores are computed only in
  SQL; a client cannot send points. Hidden data reaches only the players allowed to see it.
- Match end: the existing `_finish_match` (ranks, XP, statistics, history) — idempotent
  (`rewards_processed`). A match also ends safely when fewer than 2 players are left.
- Disconnects: a player who left is skipped; if the player whose turn it is leaves, the turn closes
  (the app asks the server at once). Host changes use the existing heartbeat / `_ensure_host` logic.

Realtime: the existing room signal (CDC + data-free "poke") triggers a re-fetch of `get_mode_state`.
Strokes use a separate data-free "ink" broadcast; receivers fetch new strokes incrementally with
`get_strokes` (plus a 1.2 s poll while a drawing is open). Measured on the local stack: strokes reached
another client 14 ms after the drawer's batch was saved.

## Rules and scoring
| Game | Players | Flow | Points |
|---|---|---|---|
| Gizli Kelime | 3–10 | describer rotates; describes aloud, others type guesses; round ends when all guessed or time is up | 30, 25, 20, 15, 10 … for the 1st, 2nd … correct guess; describer +10 per correct guess |
| Sessiz Sinema | 3–10 | actor mimes (same room, no camera); first correct guess ends the round | 20 + up to 20 speed bonus; actor +20 |
| Çiz ve Tahmin Et | 3–10 | drawer draws live (colours, sizes, eraser, clear); hint shows the length; others guess | 10 + up to 40 speed bonus; drawer +8 per correct guess |
| Anlat Bakalım | 4–10 | two teams (alternating by join order); narrator explains without 5 forbidden words; teammates type or say the word (narrator confirms), 3 passes, opponents press "Yasak kelime!" | ±1 team point per card (each team member ±10) |
| Bilgi Arenası | 2–10 | same question for everyone, 4 options, 20 s; reveal with the explanation | 100 + up to 50 speed bonus |
| İki Doğru Bir Yalan | 3–10 | everybody writes 3 statements and marks the lie; then one vote per author | finder +10, author +5 per fooled player |
| En Muhtemel Kim? | 3–10 | prompt; vote for someone else (not yourself) | +10 if you picked the room's choice; the chosen player gets a round "title" |
| Kelime Zinciri | 2–10 | turns; the next word starts with the last letter (ş/s, ç/c, ğ/g … count as one); no repeats; 3 lives | 10 + 1 per letter over 4 (max 15); survivors +15 |
| Çizim Telefonu | 3–10 | each player gets a phrase; draw / guess steps alternate (each player sees only the previous item of the chain they hold); showcase at the end | +10 per step; +20 to every contributor when the last guess names the start (even number of players) |

Settings: round time is used by the describing / drawing / writing phases (clamped to 45–120 s where
noted in the room settings); round count = turns / questions; Kelime Zinciri turns = rounds × players.

## Content
CC0, written for LOOPA: 139 words (Gizli Kelime), 120 drawable words, 91 charades (films, proverbs,
actions, jobs, animals), 60 taboo cards, 98 quiz questions with explanations (geography, history,
science, sport, arts, general knowledge), 60 "En Muhtemel Kim?" prompts, 60 telephone phrases.
Kelime Zinciri accepts the dictionary categories hayvan, bitki, eşya, yemek, meslek, şehir, ülke plus a
498-word everyday list (`chain_lexicon`). Content is picked without repeats within a match.

## Fix found on the way: room lock order (affects every game, İsim Şehir too)
`room_heartbeat`, `leave_room` and `_leave_all_rooms` locked the player row before the room row,
while `set_ready`, `update_room_settings`, `start_match` … lock the room first. Concurrent calls
(e.g. the 10-second heartbeat and "Hazır") could deadlock and PostgreSQL aborted one of them; the
multi-client E2E test hit it once. `20261115000003_room_lock_order.sql` makes all three take the room
lock first. `supabase/tests/lock_order_stress.sh`: 1,600 parallel calls gave **476 deadlocks before**
and **0 after**. This bug is also present on the hosted project today (since 0.1).

## Known limitations
- Not tested on a phone or against the hosted project.
- Sessiz Sinema / Gizli Kelime / Anlat Bakalım assume players in the same place (no voice or camera).
- Live drawing is incremental fetch on a hint, not a stroke stream: fine for a party room, not for
  hundreds of viewers.
- İki Doğru Bir Yalan statements are user-written text visible to the room; there is no report / block
  feature yet (needed before a public release under Play's UGC policy).
- The weekly rotation is still not started (`anchor_week` null): Free hosts can host only İsim Şehir
  until an admin sets the launch week (`admin_set_rotation_anchor`).
