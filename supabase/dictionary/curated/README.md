# Curated LOOPA word lists (CC0)

One entry per line: `Canonical|alternative spelling|alternative spelling`.
Lines starting with `#` are comments. Case, Turkish characters, spaces and
punctuation do not matter for matching (`dict_key`), so only list genuinely
different spellings or names (e.g. `Gaziantep|Antep`, `Amerika Birleşik Devletleri|ABD|Amerika`).
Written for LOOPA and dedicated to the public domain (CC0 1.0).
